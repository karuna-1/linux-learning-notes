# Linux Learning Notes

## Day 1 - June 4, 2026

Today I learned the basics of the Linux filesystem and practiced essential Linux commands.

## Commands Practiced

- pwd – Checked current directory
- ls – Listed files and folders
- ls -la – Viewed hidden files
- cd – Navigated directories
- mkdir – Created folders
- touch – Created files
- cp – Copied files
- mv – Renamed files
- rm – Deleted files
- cat – Viewed file contents
- grep – Searched text in files
- find – Located files
- which – Found command locations
- chmod – Learned about permissions
- whoami – Checked current user
- uname -a – Viewed system information
- df -h – Checked disk usage
- top – Viewed running processes
- ping – Tested network connectivity
- curl – Retrieved data from URLs

## Key Takeaways

- Linux uses a hierarchical filesystem.
- Everything starts from the root directory `/`.
- The terminal can be used to efficiently manage files and folders.
- Linux knowledge is a core skill for DevOps engineers.
